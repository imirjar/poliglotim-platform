# APISIX API-GATEWAY

Language courses platform

## Consists of:
1) Golang based api
2) Flutter web client
3) Keycloak SSO 
4) APISIX API Gateway with AOUTH 2.0 logic


## Start command:
```bash
docker-compose up -d 
```

## Retart command in case of updates:
```bash
docker compose down -v                                  
docker compose up -d --build
```
